## 📌 About the Internship

The internship focused on building a strong practical foundation in **cybersecurity and ethical hacking** — covering security fundamentals, social engineering, malware analysis, networking essentials, and hands-on penetration testing using **Kali Linux**. It followed a structured, week-wise curriculum combining conceptual learning, hands-on labs, and weekly assessments, culminating in a Capstone Project / Internship Grade Point Assessment.

**Organization:** EduSkills Academy (ISO 9001:2015 & ISO/IEC 20000-1:2018 certified) — runs the AICTE–EduSkills Virtual Internship Program under the patronage of the **AICTE National Internship Portal**.

---

## 🎯 Objectives

- Understand the purpose, legality, tools, and techniques of ethical hacking
- Understand core cybersecurity principles, threat types, and protection practices
- Identify and prevent social engineering attacks such as phishing and impersonation
- Learn different malware types and how to identify, analyze, and mitigate them
- Understand networking essentials — protocols, IP addressing, device configuration
- Learn Kali Linux basics, navigation, and its toolset
- Build and assess simple web applications for vulnerabilities
- Perform hands-on penetration testing and report vulnerabilities using Kali Linux

---

## 🗓️ Week-wise Curriculum

| Week | Module | Description |
|---|---|---|
| 1 | Introduction to Ethical Hacking | Purpose, legality, tools, and techniques of ethical hacking to prevent cyber threats |
| 2 | Fundamentals of Security | Cybersecurity principles, threat types, and protection practices for systems and data |
| 3 | Social Engineering | Identifying and preventing attacks like phishing and impersonation |
| 4 | Malware and Their Types | Identifying, analyzing, and mitigating different malware types |
| 5 | Networking Essentials | Networks, protocols, IP addressing, and basic device configuration |
| 6 | Introduction to Kali Linux | Kali Linux basics, navigation, and tools for ethical hacking and penetration testing |
| 7 | Basic Web Application with Capstone Projects (Vulnerability Assessment) | Building simple web apps and assessing vulnerabilities through practical projects |
| 8 | Penetration Testing (Using Kali Linux) | Hands-on penetration testing using Kali Linux tools and vulnerability reporting |
| Final | Capstone Project / Internship Grade Point Assessment | Final evaluation based on weekly performance, project submissions, and final test |

> **Note:** There was no stipend associated with this internship.
